# שיעורים

אפליקציית PWA ללימוד יומי מתוך הדפוס — רמב״ם שלושה פרקים ליום ופרק תניא לפני התפילה. עברית מלאה, RTL, מותאמת למובייל.

**כתובת האפליקציה** — `android.url` שבתצורה.

## הפעלה ראשונה

1. הריצו מול פרויקט ה-Supabase (`supabase.url` שבתצורה), דרך ה-SQL Editor,
   את `gius/migrations/000_schema.sql` ואז את `migrations/000_schema.sql` —
   הבעלים ראשון, והרצה חוזרת אינה משנה דבר.
2. הסריקות במאגרי קבצים נפרדים, שמתפרסמים ב-GitHub Pages: `shiurim-rambam` — `r/` רמב״ם לעם
   ומורה השיעור, `v/` דפוס וילנא · `shiurim-files` — `p/` עמודי התניא. הכתובות — `RAMBAM_URL` ו-`FILES_URL`.

## מסכים

- **רמב״ם** — בורר השיעור, השיעור הנוכחי מתוך רמב״ם לעם, מהדורת וילנא עם המפרשים, ומורה השיעור השנתי.
- **תניא** — בורר הפרשה, הפרק של השבוע עם לוח התיקון והערות ותיקונים, ושאר הפרקים.

## פיתוח

הקליפה ב-`index.html`, והקוד ב-`app/` וב-`core/` — מודולים שהדפדפן טוען כמות שהם. אין build.

```bash
node tools/guard.mjs       # שומר הדחיפה — חובה לפני כל push
node tools/gen-app.mjs     # מחדש מהתצורה את קובצי הפלטפורמה והאייקונים
```
